# Al-Nukhba Card Portal

Registration portal for the Al-Nukhba Card (Kuwait Hospital × GlobeMed).

- **GlobeMed staff** sign in with their work account and submit registrations.
- **Kuwait Hospital IT** sign in to review, update status (New → Missing data → Verified → Uploaded to Apex) and download Excel.

Hosting: GitHub Pages · Sign-in: Microsoft Entra ID · Data: SharePoint list (never stored on GitHub).

Setup: see **[SETUP.md](SETUP.md)**. Settings: **config.js** (empty = demo mode).
